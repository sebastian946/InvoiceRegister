# frontend

Interfaz web de InvoiceRegister: React, TypeScript, Vite y Tailwind CSS.
La documentación completa está en el [README principal](../README.md).

```bash
npm install
npm run dev      # http://localhost:5173, reenvía la API a http://127.0.0.1:8000
npm run build    # genera dist/, que FastAPI sirve en producción
npm run lint
```
